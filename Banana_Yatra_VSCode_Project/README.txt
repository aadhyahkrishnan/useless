Project Description:
BANANAMETER is a fun Kerala-only distance calculator that measures journeys in bananas instead of boring kilometres. Choose your districts, pick a destination type, choose your banana, and let the website tell you how many bananas your journey is worth!

The Problem (that doesn't exist):
People have been suffering from the terrible inconvenience of knowing distances in kilometres.
We bravely solve the completely unnecessary problem of “How many bananas is my journey?” because nobody should have to travel without knowing their banana distance. 

[What ridiculous problem are you solving?]
We are solving the world's most unnecessary problem: the lack of a proper banana-based distance measurement system.

The Solution (that nobody asked for)
We replace kilometres with bananas!
Our website uses location data and calculates the journey, then converts the distance based on the size of your chosen banana—because apparently Nendran and Robusta cannot be expected to measure distance equally.

[How are you solving it? Keep it fun!]
We take the distance between two places, divide it by the length of your chosen banana, and proudly tell you how many bananas it would take to cover the journey. Because apparently, this is the measurement system the world was missing.

Technical Details:
Technologies/Components Used

For Software:

Languages used: HTML, CSS, JavaScript
Frameworks used: None — built using vanilla web technologies
Libraries/APIs used: Photon (OpenStreetMap geocoding), OSRM (OpenStreetMap-based routing)
Tools used: Visual Studio Code, Git, GitHub, Live Server

Implementation

For Software:
The user selects a starting district in Kerala.
The destination is selected by choosing a district, place category, and famous location.
Photon/OpenStreetMap is used to fetch location data, while OSRM calculates the road distance between the starting district and destination.
The calculated distance is converted from kilometres into the number of bananas, based on the selected banana type and its approximate length.
The result displays the distance, banana type, banana count, banana value, and a funny message.
